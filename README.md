1. Download this branch as a ZIP (`Code -> Download ZIP`) and extract it.
2. Double-click `assemble.bat` (or run `copy /b KodAct-Setup-0.1.0.exe.part00+KodAct-Setup-0.1.0.exe.part01+KodAct-Setup-0.1.0.exe.part02 KodAct-Setup-0.1.0.exe`).
3. Verify SHA-256: `938184771eb734224f50026a95197e2453b60d193a83bb8f1b52fd5802d0728f`
4. Run `KodAct-Setup-0.1.0.exe`.
